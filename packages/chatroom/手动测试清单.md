# 手动测试清单（浏览器里手点）

> **启动**：双击 `启动服务.cmd`（会自动开浏览器；关掉那个黑窗口 = 停止服务）
> **为什么还要手动**：自动化测试跑的是"服务端逻辑"（`dev/e2e-check.py`，纯 HTTP）和"元素 id 对不对"
> （`dev/ui-check.py`），但**看得见的东西**（布局、滚动、弹窗、密码框、手机抽屉）只有人能判断。
> 每一项都写清了「怎么做」和「应该看到什么」，不通过就把那一步记下来。

准备：**两个浏览器窗口**（一个普通窗口 + 一个无痕窗口，或者电脑 + 手机），用来扮演两个人。

---

## 第 1 组 · 登录与注册（先把这个走通，后面才有得测）

| # | 怎么做 | 应该看到什么 |
| --- | --- | --- |
| 1.1 | 打开 <http://localhost:8000> | 正中间一张卡片：「进入聊天室」+ 用户名 + 密码 + 琥珀色「登录」按钮 |
| 1.2 | 什么都不填直接点「登录」 | 浏览器自带的"请填写此字段"提示，不跳转 |
| 1.3 | 用户名填 `a`、密码填 `123`，点登录 | 卡片内出现红框提示（用户名/密码格式不对），**不刷新页面** |
| 1.4 | 用户名 `阿哲`、密码 `password123`，点「注册一个」再提交 | 直接进入聊天页；右上角显示「阿哲」 |
| 1.5 | 刷新页面（F5） | **还在聊天页**，不用重新登录（Cookie 还在） |
| 1.6 | 再开一个窗口，用同一个账号登录 | 也能进；**第一个窗口不会被踢下线** |
| 1.7 | 点右上角「退出登录」 | 回到登录卡片；再刷新一次仍然是登录卡片 |
| 1.8 | 用错误密码登录 5 次 | 第 6 次提示"失败次数太多，请 X 秒后再试" |

## 第 2 组 · 建房间与房间码

| # | 怎么做 | 应该看到什么 |
| --- | --- | --- |
| 2.1 | 点左栏的 **＋** | 弹出卡片（和登录卡片同款样式）：「新建房间」+ 房间名 + 谁能进来 + 琥珀色按钮 |
| 2.2 | 房间名留空点「创建房间」 | 弹窗内红字提示；蒙层不关 |
| 2.3 | 填「产品讨论」，保持「凭房间码」，点创建 | 弹窗关闭；左栏出现「产品讨论」并高亮；顶部标题变成 `# 产品讨论` |
| 2.4 | 看右栏「房间码」 | 6 位大写码（不含 0 O 1 I L）；旁边有「复制」「重置」 |
| 2.5 | 点「复制」 | 右下角提示"房间码 XXX 已复制"（局域网 http 下走的是兜底方案，也要能复制成功） |
| 2.6 | 点「重置」→ 确认 | 房间码变成新的；旧码作废 |
| 2.7 | 在弹窗里点蒙层 / 点右上角 × / 按 Esc | 三种方式都能关掉弹窗 |

## 第 3 组 · 两个人进同一个房间（核心场景）

| # | 怎么做 | 应该看到什么 |
| --- | --- | --- |
| 3.1 | 无痕窗口注册 `老周`，登录后点左栏 **⌨** | 弹出「加入房间」：只有一个房间码输入框（打字自动转大写、字距很宽） |
| 3.2 | 输入错误码 `ZZZZZZ` | 弹窗内红字"房间码无效" |
| 3.3 | 输入正确码（可小写） | 弹窗关闭并提示"已加入《产品讨论》"；左栏立即出现这个房间 |
| 3.4 | 阿哲这边（不刷新） | 右栏成员数变 2；**左栏那一行的「2 人」也跟着变** |
| 3.5 | 阿哲发一条消息 | 两边**几乎同时**出现；阿哲这边自己的消息左侧有一条淡琥珀底 |
| 3.6 | 老周正在看别的房间时，阿哲发消息 | 左栏那个房间右侧冒出琥珀色未读数字角标 |
| 3.7 | 老周点进那个房间 | 角标立刻消失 |
| 3.8 | 两边都发几条，中间夹着换行（Shift+Enter） | 换行保留；消息顺序两边一致 |
| 3.9 | 老周关掉页面 / 关掉无痕窗口 | 阿哲右栏里老周从「在线」变成「离线」（顶部"在线 N"也减 1） |

## 第 4 组 · 消息类型与输入

| # | 怎么做 | 应该看到什么 |
| --- | --- | --- |
| 4.1 | 点「图片」选一张本地图片 | 先显示"上传中…"，随后出现图片缩略图（右下角浮着文件名 · 大小 · 点击看原图） |
| 4.2 | 点缩略图 | 新标签页打开原图 |
| 4.3 | 截图后直接在输入框里 **Ctrl+V** | 图片自动上传并发出 |
| 4.4 | 点「文件」选一个 `.py` 或 `.txt` | 出现文件卡片（扩展名徽标 + 文件名 + 大小/行数/编码 + 下载按钮），下面还有一段代码预览 |
| 4.5 | 选一个 `.exe` 或 `.zip` | 提示"只接受图片或纯文本文件" |
| 4.6 | 选一个超过 2MB 的文本文件 | 提示"文件超过 2MB" |
| 4.7 | 输入框里打一半，按 Enter | 发送出去并清空输入框 |
| 4.8 | 只打空格 / 空内容按 Enter | 什么都不发 |
| 4.9 | 一口气连发 5 条 | 5 条都按顺序出现，**不重复、不丢**（seq 去重生效） |

## 第 5 组 · 滚动与翻页

| # | 怎么做 | 应该看到什么 |
| --- | --- | --- |
| 5.1 | 一开始进房间 | 自动停在最新一条（底部） |
| 5.2 | 往上滚看历史，这时对方发消息 | **画面不跳**；底部浮出「N 条新消息 ↓」 |
| 5.3 | 点那个按钮 | 滚到底部，按钮消失 |
| 5.4 | 滚到最上面 | 顶部有「加载更早的消息」，点一下加载 30 条，**阅读位置不跳** |
| 5.5 | 一直翻到最早 | 按钮消失（没有更多了） |
| 5.6 | 消息里跨天 | 中间出现「今天 / 昨天 / 10 月 6 日」分隔条 |

## 第 6 组 · 能不能真的隔离（**这组最重要**）

| # | 怎么做 | 应该看到什么 |
| --- | --- | --- |
| 6.1 | 第三个人 `路人` 注册登录 | 左栏是空的：提示"还没有房间。＋ 新建一个，或者用 ⌨ 输入别人给的房间码" |
| 6.2 | 路人在地址栏手动改成 `/api/snapshot/1` | 返回 `{"detail":"你不在这个房间里"}`（403），**看不到任何消息** |
| 6.3 | 路人在 F12 Console 里执行 `await fetch('/api/messages/1',{method:'POST',headers:{'content-type':'application/json'},body:JSON.stringify({type:'text',text:'我是冒充的'})}).then(r=>r.status)` | 返回 `403` |
| 6.4 | 老周在 Console 里执行 `await fetch('/api/messages/1',{method:'POST',...,body:JSON.stringify({type:'text',text:'试试冒充阿哲',username:'阿哲',userId:999})})` | 消息发出去了，但**署名是老周**（服务端不认客户端传的身份） |
| 6.5 | 退出登录后按 F5 | 回到登录卡片；**看不到刚才房间里的任何消息** |
| 6.6 | 在 Console 里删掉 Cookie（`document.cookie='sid=;Max-Age=0'` 删不掉 HttpOnly，可改用 Application 面板删除），再刷新 | 回到登录卡片 |
| 6.7 | 老周点右上角「退出登录」，再用阿哲的账号在另一个窗口登录 | 两个人各自独立，互不影响 |

## 第 7 组 · 手机版（窄屏）

| # | 怎么做 | 应该看到什么 |
| --- | --- | --- |
| 7.1 | 手机连同一个 WiFi，打开 `http://<电脑IP>:8000` | 自动进入手机版（不是桌面版的三栏） |
| 7.2 | 点左上角 ☰ | 左栏房间列表从左滑出，背景压暗；点房间或点空白处收起 |
| 7.3 | 点右上角 ☷ | 右栏（成员 / 房间概况 / 房间码）从右滑出 |
| 7.4 | 看消息 | 「谁 + 时间」在消息上方一行，正文占满宽度，不需要左右滚 |
| 7.5 | 在手机上发一条 | 电脑上立刻看到；反之亦然 |
| 7.6 | 手机上锁屏 30 秒再解锁 | 回来仍能收发（SSE 断了会自动重连，状态灯变回"已连接"） |
| 7.7 | 桌面浏览器把窗口拉窄到 860px 以下 | 自动跳到手机版；地址后加 `?desktop` 可以强制看桌面版 |

## 第 8 组 · 稳定性

| # | 怎么做 | 应该看到什么 |
| --- | --- | --- |
| 8.1 | 把黑窗口关掉（= 停服务），看页面 | 顶部状态灯变黄"重连中…"，但界面不崩、不发一堆红字 |
| 8.2 | 再双击 `启动服务.cmd` | 状态灯自己变回"已连接"，**断线期间的消息自动补齐**（不重复、不丢） |
| 8.3 | 停服务再启动，然后刷新页面 | 之前发的消息都在（SQLite 持久化） |
| 8.4 | 同一账号开两个标签页进同一个房间 | 两边都能收到消息；右栏在线成员里这个人只算**一个**在线 |
| 8.5 | 发一条 3000 字的长消息 | 正常发出、正常显示 |
| 8.6 | 发一条超过 64KB 的消息 | 提示"单条内容超过 64KB" |
| 8.7 | F12 看 Console | **零报错**（有 warning 也记下来） |
