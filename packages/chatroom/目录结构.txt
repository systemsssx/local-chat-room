文档是怎么生成的（可复现）
============================================================
    # 对话记录：从 DSH 会话原始日志逐条抽取，不改写、不润色、不摘要
    node dev/make-transcript.mjs <session.v4.jsonl.zstd> 对话记录-02-实现过程.html \
         --project "聊天室" --from "方向二：聊天室" --to "把那个之前的几个说明文档搬过来"

    # 开发经历那类普通文档：改 dev/docs-src/ 里的 md，再跑这一条
    node dev/make-doc.mjs dev/docs-src/开发经历-02-聊天室.md 开发经历-02-聊天室.html "局域网聊天室 · 全栈"

    --from  从哪一条开始收（前面选题/交接的讨论不要）
    --to    到哪一条为止（整理文档这段讨论不要）
    --skip  跳过中段（可给起止两个关键字）

三条规矩
============================================================
1. 文档摊在主目录 —— 验收时一眼就能看到，不用翻文件夹；
2. data/ 和 uploads/ 不进 Git —— 它们是运行时产生的；拷走 data/app.db 就等于完成备份；
3. 接口字段只认 docs/接口契约.md —— 改字段先改契约，再改两边代码。

怎么跑
============================================================
    python -m pip install -r requirements.txt
    python server.py                  → http://localhost:8000（手机用局域网地址）
    python -m unittest discover       → 131 项单元测试
    python dev/ui-check.py            → 前端静态检查
    python dev/e2e-check.py           → 51 项端到端（需要服务在跑）
