# 界面设计稿

## v5-chatroom.html —— 定稿的那一版

**怎么看**：双击用浏览器打开（字体走 `../../epubui/...` 的相对路径，直接开文件时会退回系统字体，
样子差不多但不完全一样）。要给设计稿用真字体出图，需要从 `C:\work` 起一个静态服务器再打开。

页面右下角有一个「聊天页 / 登录页」切换条 —— **那是设计稿专用的**，实际页面里没有。
地址后加 `#login` 可以直接看登录卡片。

### 这一版相对上一版（协同剪贴板）改了什么

| 位置 | 改成 | 为什么 |
| --- | --- | --- |
| 左栏 | 三种传输方式的"通信方案" → **房间列表** | 只保留 SSE 之后，"三条管子"这个结构就不存在了；左栏空出来正好放房间 |
| 顶栏 | 房间号输入框 + 昵称输入框 → **当前房间铭牌 + 我** | 房间从列表里选、身份来自登录，这两个输入框没有存在的必要 |
| 消息行 | 去掉 POLL/SSE/WS 管道标记 | 只剩一种管子，标它没有意义；位置让给头像 |
| 右栏 | 去掉"历史记录（最近 20 条）"卡片 | 消息流本身就是历史，顶部「加载更早的消息」代替；右栏让给成员、房间概况、房间码 |
| 底栏 | 去掉"纯文字 / 剪贴板读取"模式切换 | 剪贴板监听是上一个项目的能力，聊天室用不上 |
| 新增 | **登录 / 注册卡片**、**建房间 / 加入房间弹窗** | 身份与房间都需要入口；两处弹窗和登录卡片共用一套样式（`.login-card` 那组类） |

配色与字形**沿用**原来的精密仪表皮肤（暖炭灰机箱 + 单一琥珀强调 + Cascadia Mono 标签 + Georgia 数字）——
改动量小，也是已经验收过的风格。

### 设计上的几个决定

1. **琥珀色只用在"强调与状态"**：当前房间的左侧竖条、未读角标、在线状态灯、主按钮。
   正文和边框一律是灰阶，这样一屏里琥珀色出现的每一处都是"这里有信息"。
2. **房间行两行结构**：第一行是房间名 + 人数，第二行是最后一条消息的摘要；右侧是时间和未读角标。
   扫一眼就知道"哪个房间有新消息、是谁说了什么"。
3. **消息行沿用日志式布局**（左边一栏"谁 + 时间"，右边正文），不是左右气泡 ——
   群聊里几十条消息连着刷，对齐的正文列比来回跳的气泡好读。
4. **空状态是邀请而不是说明**：没有房间时左栏写"＋ 新建一个，或者用 ⌨ 输入别人给的房间码"，
   新房间里写"《XX》还没有消息 —— 在下面发第一条"。
