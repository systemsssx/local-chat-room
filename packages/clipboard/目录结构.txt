三条规矩
------------------------------------------------------------
1. 所有文档都在主目录 —— 验收时一眼就能看到，不用翻文件夹；
   文档的源文件在 dev/docs-src/（改内容改源文件，再跑一条命令重新生成）
2. data/ 和 uploads/ 不进 Git —— 它们是运行时产生的，拷走 data/app.db 就等于备份
3. alt-node/ 只是留档 —— Node 版实现过同一套接口契约，留着对照，删掉不影响运行

怎么跑
------------------------------------------------------------
双击 启动服务.cmd     → 服务起来，浏览器自动打开，窗口里打印手机该访问的地址
双击 跑单元测试.cmd   → 103 项单元测试，约 1.2 秒（不需要启动服务）
连不上手机时          → 右键 放行防火墙.cmd → 以管理员身份运行
