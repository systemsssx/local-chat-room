协同剪贴板（局域网）前端设计稿。**结构三版完全一致，只有皮肤不同** —— 方便直接对比取舍。

## 结构（三版共用）

```
┌──────────── 侧边栏 400px ────────────┬──────────── 大栏 ────────────┐
│ 品牌块                                │ 房间 1001 · 三种通信方案      │
│ ── 板块一 文字 ──                     │ ┌─P1 HTTP轮询─┬─P2 SSE─┬─P3 WS─┐│
│   小栏 1 纯文字共享（房间号/进入/状态/  │ │ 接口路径     │        │       ││
│          内容框/最近更新）             │ │ 指标读数     │        │       ││
│   小栏 2 剪贴板自动读取（开关/来源/     │ │ 传输时序带   │        │       ││
│          最近读取/安全上下文提示）      │ │ 实时事件流   │        │       ││
│ ── 板块二 历史 ──                     │ │ 一句话说明   │        │       ││
│   小栏 1 最近 20 条（可恢复）          │ └─────────────┴────────┴───────┘│
│   小栏 2 存储（SQLite / 快照 / 导出）   │ 三种方式的区别（对照表）        │
│ ── 板块三 图片 ──                     │  方向 / 连接 / 开销 / 延迟 / 断线│
│   小栏 1 上传·粘贴（≤2MB）            │                                │
│   小栏 2 图片流（WS 广播预览）         │                                │
│ 底栏 局域网地址 · 房间 · 连接数        │                                │
└──────────────────────────────────────┴────────────────────────────────┘
```

对照表内容对应 README 必写项「轮询 / SSE / WebSocket 的区别」，不是装饰。

## 怎么改

改样式**只动 `skins/*.css`**，改结构或文案动 `_body.html`，然后：

```powershell
python design/build.py                            # 重新合成 HTML
python design/shot.py                             # 重新截图（三个一起）
python design/shot.py v2-console                  # 只截某一个
```

截图需要本地静态服务（字体走同源相对路径加载，直接 file:// 打开会掉字体）：

```powershell
python -m http.server 8899 --directory C:\work --bind 127.0.0.1
# 然后浏览 http://127.0.0.1:8899/collab-clipboard/design/v1-patch-panel.html
```

## 字体

## v4 定稿说明（四面框）

```
┌─────────────────────────────────────────────────────────────────────────┐
│ 上：品牌 · 房间 1001 · CH2×纯文字(2×3组合)   [纯文字│剪贴板读取]  昵称·状态 │
├──────────┬──────────────────────────────────────────────┬───────────────┤
│ 左：      │ 信息显示窗口（聊天流，每条横向占满）             │ 右：           │
│ 三种方案   │  张明 .9  14:23:05  文字                      │ 在线成员(信号格)│
│ 五段LED   │  我 .7    14:22:41  图片缩略图                 │ 房间/服务信息   │
│ 电平梯    │  平板 .12 14:20:12  clipboard.py + 代码预览      │ 历史(SQLite)   │
│ 房间/昵称  │  …                                            │               │
├──────────┴──────────────────────────────────────────────┴───────────────┤
│ 下：[输入要共享的内容…] 🖼图片 📄文件  提示文案            [ 发送 ]        │
└─────────────────────────────────────────────────────────────────────────┘
```

- 切到「剪贴板读取」模式时，下侧栏输入框消失 → 换成监听状态条（本机剪贴板 → 房间）
- 仪表件：左栏每方案一条**五段 LED 电平梯**（点亮程度＝该方案流量）、信息窗顶栏**实时电平条 + 读数**、右栏成员**信号强度格**
- 发送者＝昵称 + IP 短尾；自己的消息行有琥珀色左向渐变底

产物：`v4-console-chat.html` / `shots/v4-console-chat.png`
